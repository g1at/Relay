# Relay 悬浮球日志采集工具

适用于 Windows 10 / 11，包括已经安装的 **Relay 3.0.1**。无需升级 Relay、安装 Node.js 或使用管理员权限。工具只读取窗口技术指标，不会启动、关闭、重启、移动或修改 Relay。

## 给反馈用户的操作步骤

1. 把工具 ZIP **完整解压**到任意可写目录（不要在压缩包内直接运行），保留四个文件在同一目录。
2. 正常打开 Relay 和悬浮球，双击 **`collect-orb-log.cmd`**。
3. 确认窗口提示“已检测到 1 个悬浮球窗口”。悬浮球正常时，切回采集窗口，按 **B**（无需回车）。
4. 回到悬浮球，像平常一样拖动；出现切割后，切回采集窗口，按 **F**。先保留异常几秒钟，方便采样。
5. 在 Relay 中关闭再开启悬浮球，确认恢复后，切回采集窗口，按 **R**。
6. 再等几秒，按 **Q** 结束。将控制台显示的 **ZIP 文件**发送给维护者，并说明 Relay 版本、触发动作、是否跨显示器拖动。

默认结果保存在桌面的 **`Relay-Orb-Logs`** 文件夹内。每次运行会生成独立子目录和同名 ZIP，不覆盖已有结果。默认最多运行 15 分钟，到时自动结束并打包。请按 **Q** 退出；直接关掉控制台或断电可能来不及打包，但已经写入的日志仍在结果目录。

如果公司策略阻止脚本运行，请把错误信息告知维护者，不需要修改系统策略。本工具的 `-ExecutionPolicy Bypass` 仅用于本次 PowerShell 进程，不更改持久执行策略，也无法绕过公司强制策略。

工具**不自动截图**。若方便，可自行截图，仅保留悬浮球和少量周围区域；日志可以判断尺寸、缩放与窗口裁剪区域是否变化，截图用于判断实际画面是否被切割。

## 采集范围

| 会采集 | 不会采集 |
| --- | --- |
| Windows 版本、架构，PowerShell 版本，时区偏移 | 电脑名、用户名、IP、显示器序列号 |
| 显示器坐标、工作区域、有效 DPI / 缩放；布局变化 | API Key、账户、Relay 配置、聊天、任务内容 |
| GPU 名称、驱动版本/日期、当前分辨率 | 进程命令行、安装路径、用户文档 |
| 悬浮球窗口坐标、尺寸、客户区、DPI、原生裁剪区域、DWM 边界及状态 | 屏幕截图、桌面录像、其他应用窗口标题 |
| 对应进程名、PID、启动时间、内存和累计 CPU；窗口出现/消失；B/F/R 标记 | 网络请求、上传行为、Relay 内部日志全文 |

窗口只接受**精确标题 `Relay 悬浮球`，且进程名为 `Relay` 或 `electron`** 的组合，因此兼容正式版与开发版。系统窗口标题只在内存中进行匹配，不把其他标题写入日志。所有数据均留在本地，由用户决定是否发送。窗口坐标可能反映屏幕排列，请先审阅再分享。

## 文件内容与解读边界

- `environment.json`：系统、GPU、初始显示器布局，以及采集参数。
- `samples.jsonl`：默认每 250 毫秒一条悬浮球采样；每行一个 JSON 对象，`windows: []` 表示当时没有匹配窗口。
- `events.jsonl`：用户标记、窗口出现/消失、显示器变化与采集错误。
- `summary.json`：采集起止时间、结果统计及退出原因。

原生坐标以物理像素为单位，具体以 `physicalCoordinatesRequested` 字段为准；窗口缩放以该窗口的 `dpi` 为准。`windowRegion.type = 0` 通常是“没有设置独立裁剪区域”，**不能解读为可见区域为空**。DWM/分层窗口属性不可用也不自动代表故障。

`instance` 用 PID、进程启动时间及 HWND 关联；检测到消失后再次出现会产生新实例。若同一 HWND 在两次采样之间被极快销毁并复用，可能无法辨别。指标来自操作系统，无法直接证明 Chromium 页面或 GPU 画面是否正确；需结合 F 标记、截图和复现步骤。

## 可选命令行（维护者）

在此目录运行以下命令，自动采集 20 秒后结束，不等待输入：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Collect-RelayOrbLog.ps1 -NonInteractive -DurationSeconds 20 -OutputRoot "$env:TEMP\Relay-Orb-Logs"
```

`DurationSeconds` 范围为 5–1800 秒；`IntervalMilliseconds` 范围为 100–2000 毫秒。无人值守运行也有时间上限。脚本只有四个随附文件，无外部依赖；临时 GDI 区域和文件句柄在 `finally` 中释放。

分发时将本目录的 `collect-orb-log.cmd`、`Collect-RelayOrbLog.ps1`、`RelayOrbNative.cs` 和 `README.md` 压缩为一个 ZIP 即可，不要混入真实用户的日志。
