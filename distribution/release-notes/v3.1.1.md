# Relay 3.1.1 更新说明

发布日期：2026-11-12

本次更新修复记忆创建与更新中的兼容性问题，并避免已完成的视频会话在每次重启后重新出现在“今天”。

## 🧠 记忆可靠性

- 修复部分模型新建记忆时将空版本号传为字符串 `"null"` 导致失败的问题；对其他非法版本号提供明确错误提示。候选审批流程与更新时的版本冲突检查继续保留。
- 后续创建的记忆候选使用有长度限制的可读文件名，多轮更新不再反复叠加 `-draft-UUID` 后缀；已有记忆文件和引用保持原样。
- 读取已被替代的旧记忆时，提示当前任务可访问的最新替代条目，引导模型重新读取后再更新，避免只收到“当前任务不可访问这条记忆”。
- 补充记忆工具调用、参数校验和版本冲突的脱敏诊断，便于通过日志定位失败原因。

## 🎬 视频会话日期

- 修复恢复已完成的视频任务时重复刷新会话活动时间的问题，避免历史视频会话在每次重新打开 Relay 后反复跳到“今天”。

## 升级说明

结束或暂停正在执行的任务，退出 Relay（包括托盘实例），再运行 `Relay-3.1.1-Setup.exe` 覆盖安装。已有会话、服务商、项目、技能与记忆配置继续保留，无需删除用户数据目录。

Windows x64 安装包和后续更新统一通过 [g1at/Relay](https://github.com/g1at/Relay/releases/latest) 提供。
