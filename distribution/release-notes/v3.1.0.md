# Relay 3.1.0 更新说明

本次更新重点带来 **图片与视频创作升级、更可靠的定时任务，以及更流畅的长任务和多任务体验**，同时整理了服务商设置、内置浏览器和记忆界面。

## 🎨 图片与视频创作

- AI 创作加入视频生成，支持按模型能力使用文字或参考图片生成，并在会话中直接查看图片、播放视频。
- 模型配置简化为「刷新模型 → 勾选添加 → 保存」。可识别的模型自动填写模板，其他模型选择一次模板即可继续配置，高级选项仍保留。
- 按通用协议接入模型，可用于不同服务商和中转网关；同一协议下增加模型无需逐个编写执行适配。
- 补齐并校正图片尺寸、比例、画质、数量，以及视频时长、分辨率、声音等参数。常用项更紧凑，尺寸提供快捷预设和自定义宽高。
- 模型和生成参数按会话独立保存，每次提交保留当轮设置，切换对话不会串用选择。
- 图片与视频分别调度，支持多个生成任务并行，减少相互等待。
- 统一创作与聊天的错误展示，复用输入框按钮控制任务；已知远端任务可继续查询，文件下载失败可单独重试。

模型是否可用、具体参数及生成速度仍取决于网关和当前密钥权限。「停止等待」只停止本地等待，不代表远端任务取消或停止计费。

## ⏰ 定时任务更可靠

- 修复任务时区计算，正确处理指定时区、跟随系统时区及夏令时切换。
- 通过工具执行定时任务时，明确区分已接收、排队、正在运行和失败，避免把提交成功当成任务完成。
- 完善从排队到结束的运行记录，应用重启后可识别未完成的任务。
- 定时创作可选择图片或视频模型，并使用与 AI 创作一致的参数设置。

定时任务仍需要 Relay 保持运行。

## 💬 对话、历史与运行体验

- 历史会话新增未读蓝点，便于找到后台任务的新结果，查看后清除。
- 改善异常退出后的任务状态与过程恢复；重新打开后保留已保存内容，由你决定何时继续。
- 优化历史全文搜索、匹配定位和索引更新，减少大量会话下的重复读取。
- 减少长回答、代码块和折叠过程记录的重复渲染，改善流式输出、拖动侧栏和多任务切换时的卡顿。
- 改善工具连接等待、终端退出及历史保存失败后的处理，减少无响应、残留等待和历史列表不同步。

## 🌐 浏览器与工作区

- 内置浏览器增加面向当前任务的网页操作能力，支持页面观察、交互、截图、下载与结果核验。
- 浏览器任务按会话隔离，支持用户接管；恢复后重新检查页面状态再继续。
- 改善浏览器标签页的网站图标、连接状态与菜单展示。
- 右侧文件树按钮增加展开/关闭状态，减少与侧栏折叠按钮混淆。
- 收紧过宽的弹窗、菜单和托盘内容，改善默认窗口下的布局。

## ⚙️ 设置与记忆

- 精简设置说明，统一控件、下拉框和弹层风格，移除输入框多余光效。
- 服务商名称的必填提示更清晰；保存失败时提供明确原因和有限重试，保留原配置与编辑草稿。
- 改善服务商详情、图片/视频模型列表及参数区域的紧凑布局，视频模型使用独立图标。
- 快捷键修改采用更轻量的录制交互，浏览器和快捷键设置页的板块密度更一致。
- 记忆候选集中展示，查看来源、确认和归并更直观；补充项目关联异常提示。
- 完善记忆分类与筛选、候选操作限时撤销，以及已移除记忆的恢复和永久删除。

## 升级说明

结束或暂停正在执行的任务，退出 Relay（包括托盘实例），再运行 `Relay-3.1.0-Setup.exe` 覆盖安装。已有会话、服务商、项目、技能与记忆配置继续保留，无需删除用户数据目录。

Windows x64 安装包和后续更新统一通过 [g1at/Relay](https://github.com/g1at/Relay/releases/latest) 提供。
